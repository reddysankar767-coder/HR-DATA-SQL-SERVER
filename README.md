
# SQL Server HR Database Project

##  Project Overview

This project is an **HR Database Management System** developed using **Microsoft SQL Server and T-SQL**.

The database contains information about **employees, departments, jobs, locations, countries, regions, and job history**. The project focuses on writing SQL queries for **real-world HR data analysis and SQL interview preparation**.

##  Database Tables

* `employees` – Employee details, salary, manager and department
* `departments` – Department information
* `jobs` – Job titles and salary ranges
* `locations` – Office location details
* `countries` – Country information
* `regions` – Regional information
* `job_history` – Employee job/department history

##  SQL Interview Queries

The project includes commonly asked SQL interview problems such as:

* Find the **second-highest salary**
* Find the **Nth-highest salary**
* Find the **top 3 highest-paid employees**
* Find the **highest-paid employee in each department**
* Find the **top 2 employees in each department**
* Find employees earning **more than the average salary**
* Find employees earning **more than their manager**
* Find departments with **more than 5 employees**
* Find **duplicate employee records**
* Find employees with **no manager**
* Find departments with **no employees**
* Find employee and **manager details using SELF JOIN**
* Find employees who **changed jobs/departments**
* Find salary **ranking using window functions**
